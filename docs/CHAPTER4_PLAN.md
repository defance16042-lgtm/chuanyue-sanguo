# 第四章企劃：許都風雲（草案）

接在第三章下邳（高順、典韋離隊、《三略》線索）之後。史實段落：白門樓之後，曹操迎獻帝遷許都、煮酒論英雄、衣帶詔、劉備叛曹、過五關、官渡。基調：前半搞笑（煮酒論英雄、貓妖被曹操盤問），後半嚴肅（官渡、關羽辭曹）。

## 劇情
1. 序：下邳事了，劉備一行被曹操接往許都。貓妖發現「歷史開始照他讀過的版本走」，卻也處處被他改動。
2. 許都：覲見獻帝、領左將軍之職；曹操邀飲，煮酒論英雄（對話選項小遊戲，答錯曹操起疑，不影響主線）。
3. 衣帶詔：董承密訪，貓妖左右為難（演義線）；正史線以對話交代。
4. 徐州叛曹：劉備借口攔袁術出城，殺車冑。戰鬥：車冑守軍。
5. 曹操東征，劉備敗走，關羽被圍土山（約三事：降漢不降曹）。
6. 過五關斬六將（關羽與諸葛貓妖同行；關羽是篇章核心，貓妖參與對話、探索與戰鬥。不可把貓妖安排到另一條袁紹支線而缺席，也不做成關羽完全單人不可參與的玩法）。
7. 官渡：烏巢火攻。結尾 Boss：顏良、文丑（白馬、延津），章末貓妖拿到新兵書線索，銜接第五章。

## 地圖
- 第四章獨立大地圖 'world4'（豫州、司隸東部、冀州南緣），章間以虎牢東關口／黃河渡口銜接，並用章節封鎖旗。
- 城 6：許都、汝南、白馬、官渡、延津、鄴；村 3；洞穴 2（暫名：邙山古墓、黃河洞窟）；山口／關口 5（過五關各一）。
- 沿用現有高清地形與 32px 人物，不新增圖塊種類。

## 人物與支線
- 來客：曹操（短暫同行）、荀彧、關羽（回歸／離隊段）、董承、袁紹陣營的顏良、文丑（敵）。
- 新將可招收（只經由主線擊敗後的野外殘部）：顏良、文丑、車冑部屬。
- 支線 4 條（暫定）：荀彧的糧道、董承遺信、許都盜賊、官渡探哨。
- 新兵書一本（暫名《孫子》，單體高倍率）。

## 已確認的後續主線規劃：關羽辭曹與千里走單騎

> 使用者已確認採用《三國演義》戲劇性版本，並要求保留搞笑演出。此為後續劇情規劃，尚未代表已實作進遊戲。

### 劇情方向
1. 曹操攻打徐州，劉備戰敗，與關羽等人失散。
2. 關羽留守／被困下邳一帶，遭曹軍包圍擒獲。
3. 曹操招降關羽；關羽提出降漢不降曹等條件，暫時降曹。
4. 關羽得知劉備下落後辭曹，踏上千里尋兄之路。
5. 「過五關斬六將」作為關羽的重要英雄篇章，**諸葛貓妖全程陪伴關羽同行**，不是把貓妖留在另一條袁紹支線，也不是關羽完全單人、玩家不能帶主角參與。
6. 關羽是該篇章的核心人物；諸葛貓妖參與對話、探索及戰鬥，兩人共同突破各關，之後銜接兄弟重逢與後續官渡主線。

### 搞笑與角色表現
- 劇情不能太死板：保留忠義、戰爭與英雄氣勢，同時安排角色互相吐槽、誤會、反差笑點及輕鬆對話。
- 笑點以關羽的嚴肅反差、曹操招降時的對話、關口守將的誇張反應、諸葛貓妖的吐槽等方式呈現。
- 搞笑不能削弱關羽忠義與主角同行的重要性；重要事件仍按演義主線推進。
- 五關各自設計不同守將／阻攔事件、戰鬥或突圍玩法；關羽與諸葛貓妖一起參與，不以純文字快速跳過。
