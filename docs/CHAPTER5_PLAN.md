# 第五章企劃：官渡烽火（草案）

接在第四章鄴城重逢（劉備、張飛歸隊、關羽辭曹完畢）之後。對應 STORY_MASTER_PLAN 第四篇第 16 項「官渡決戰」與第五篇第 17 項「袁紹之後」（約 200–202 年）。
基調：前半是兩大勢力的總決戰（嚴肅、緊繃），後半是劉備一行失去依靠、南下荊州（有一點苦中作樂的搞笑）。標示：官渡之戰、烏巢火攻為**史實**，許攸獻計與張郃高覽倒戈為**史實**，劉備曹操互動為**演義色彩**。

## 劇情
1. 序：鄴城。袁紹不聽田豐，反把他關進牢裡。貓妖勸劉備別待在袁營，但劉備需要時間。劉備「借口」南下汝南聯絡劉辟、龔都（呼應第四章的葛陂洞）。
2. 汝南：劉備、關羽、張飛與貓妖到汝南，和劉辟、龔都會合，打擊曹軍後方（史實）。曹仁來攻，劉備敗走。
3. 官渡對峙：袁軍在陽武紮營、築土山射入曹營；曹軍糧盡。貓妖受荀彧所託，到官渡偵察與運糧（任務型戰場：護糧、偵察、劫糧三個小關）。
4. 許攸倒戈：許攸因家人被審配下獄，投奔曹操，獻「燒烏巢」計。貓妖一行被曹操邀請同行（演義：曹操赤腳出迎）。
5. 烏巢火攻（本章核心戰）：夜襲烏巢，守將淳于瓊（Boss 戰）；火攻演出——地圖逐格起火、限回合撤退（原創玩法，戰鬥內計時，不改戰鬥核心尺寸）。
6. 張郃、高覽：袁軍後方聽說烏巢被燒，二將投降曹操（史實）。以對話與一場「陣前倒戈」小戰交代；二將為「敵將殘部」招收來源。
7. 袁紹敗走：袁軍潰逃，投降的八萬俘虜（史實爭議，只做對話交代）。貓妖看見田豐的結局，是第一次真的覺得「歷史不能改」。
8. 倉亭、病逝：倉亭之戰（曹操再破袁紹）、袁紹病逝、袁譚袁尚爭位——以對話與兩場事件戰交代。
9. 南下：劉備在汝南再敗，轉投荊州劉表。結尾：新野小城，劉表撥給劉備駐紮。貓妖在新野郊外聽到一個牧童唱「臥龍岡」，埋下三顧茅廬伏筆，銜接第六章。

## 地圖
- 第五章獨立大地圖 'world5'（豫州北部、冀州南部、荊州北部），以第四章鄴城南渡口／官渡通往此圖，章間用章節封鎖旗。
- 城：陽武（袁軍前線）、倉亭津、黎陽、新野、襄陽、汝南（沿用 world4 的汝南，不重做）；另有「烏巢」特殊戰場（一張大型單層地圖，非城鎮）。
- 村 3、洞穴 2、山口／關口 2（官渡與荊州邊界），暫名待定，開工前再和使用者確認。
- 使用既有高清地形與 32px 人物，不新增圖塊種類。

## 人物與招收（嚴格遵守：只經由主線擊敗後的野外殘部，低機率，主線不得出現）
- 主線 Boss：曹仁（汝南）、淳于瓊（烏巢）、審配部將（黎陽，原創副本）、蔡瑁（荊州邊境，原創）。
- 敵將殘部可招收：淳于瓊、曹仁部將、蔡瑁部將。許攸、張郃、高覽為客串（章末離隊，歸還裝備），不計入常駐招收。

## 技術要點
- 沿用 tools/build_ch4.py 的產生器（世界地圖、城鎮模板、村莊、洞穴）；另建 tools/build_ch5.py、data/ch5*.js，亂數與既有章節隔離（既有地圖不得改動）。
- 烏巢火攻：以地圖事件＋連續戰鬥群組實作，回合限制用戰前對話說明；不新增戰鬥核心機制，若需新機制先列清單給使用者確認。
- 等級區間預估 Lv60–70；平衡以 tools/sim_ch3.js 為範本，Boss 目標：同級約 70–90% 勝率，選擇性內容較高。
