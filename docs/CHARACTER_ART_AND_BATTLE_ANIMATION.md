# 武將原創頭像與高解析戰鬥動作美術規格

## 使用者已確認的方向
- 不要可愛 Q 版；維持《穿越三國・諸葛貓妖傳》原本遊戲人物設計與美術比例。
- 所有頭像、人物立繪、戰鬥角色與武器動作都要重新自創，不使用其他遊戲、動漫或商業作品的角色圖／素材。
- 歷史人物只取其公開歷史身份、年代服飾與武器特徵作為題材，不照搬任何現成作品的特定造型。
- 戰鬥人物提高原始美術解析度；人物全身與武器完整呈現，武器不得被裁切。
- 每位武將要依照自己設定／裝備的武器設計起手、攻擊、命中、收招動作；揮刀砍、槍矛突刺、弓箭拉弓放箭等必須看得出來。
- 同一武將在武將資料、招募、編隊與戰鬥畫面使用同一套原創人物設計與辨識特徵。

## 原創美術資產規格

### 武將頭像
- 每位武將一張獨立頭像，不以共用臉圖換名字。
- 頭像需有可辨識的臉型、髮型、鬍鬚、頭盔／冠、服裝色系與神情。
- 保留既有遊戲頭像格的相容性；新頭像以 96×96 或更高原始尺寸繪製，輸出時再製作適配版本。
- 頭像需有透明背景／乾淨邊緣，不能帶入生成用的背景、文字、標誌或其他角色。

### 戰鬥人物
- 目前戰鬥場景為 Canvas 256×224，戰鬥列高約 30 px；高解析源圖採 48×32 每格（或更高且等比例），以完整角色與武器為構圖基準。
- 戰鬥中顯示尺寸已先調整為 36×24，非原本 24×16；所有人物以中心位置對齊，武器與披風不得越界裁切。
- 後續正式 sprite sheet 必須以規則格線製作，透明背景，人物尺寸與錨點一致；不同影格不得改變頭身、武器長度或裝備細節。
- 每位武將需獨立人物列／動畫資產；不得把一般地圖小人直接當作完成的武將戰鬥美術。
- 角色全身朝向需遵循原本遊戲戰鬥方向，戰鬥時武器朝敵方出招。

## 武器動作分類
| 武器 | 專屬動作 |
|---|---|
| 劍 | 快速斜斬、回身收劍 |
| 刀／大刀 | 蓄力重斬、弧形揮砍 |
| 矛／槍 | 起手架槍、向前突刺、回收 |
| 弓 | 拉弓、瞄準、放箭、收弓 |
| 斧／戟 | 高舉重劈、橫掃 |
| 扇 | 揮扇／展扇、策略或氣流演出 |

動作影格至少包含：待機、起手、攻擊、收招、受擊、倒下。連續動作要保留武器慣性與人物重心變化，不能只讓人物平移或單純閃光代替攻擊。

## 目前已開始的程式工作
- `src/battle_logic.js`：新增武器攻擊動畫分類 `weaponAnim(wtype)`，物理攻擊依武器分為 slash／heavy／thrust／bow／fan；非物理計謀仍使用 cast。
- `src/battle_scene.js`：戰鬥人物顯示從 24×16 放大至 36×24；新增各武器不同的起手、出招與收招時間／前進幅度，敵方也使用相同武器動畫分類。
- `tests/battle_test.js`：加入武器動畫分類檢查。
- 目前仍使用既有 battle sprite sheets；因此此批程式是動作分流與顯示放大第一步，**尚未完成逐位武將的全新高解析原創頭像、武器繪製及專屬連續影格**。

## 後續製作順序
1. 盤點 `data/characters.js`、`data/battle.js`、`data/gens.js` 中所有武將／敵將與武器種類，建立完整美術清單。
2. 先完成主要武將（諸葛貓妖、劉備、關羽、張飛、曹操、呂布、趙雲、黃忠等）的頭像與戰鬥動作，確認畫風及格線。
3. 建立可擴充的戰鬥美術索引，以角色 ID 對應頭像、待機／攻擊／受擊／倒下影格，不再只靠固定 6 人列。
4. 依同一規格批次完成其餘可招募武將、主線敵將與一般敵人；武器與人物造型需一一對應。
5. 整合素材後測試 1v1、5v5、不同武器、受擊、死亡、技能與敵方攻擊；檢查武器裁切、影格跳動、位置重疊及舊存檔相容。
6. 測試通過後更新版本、README、RE_REPORT、HANDOFF，再建置 Windows 安裝包；未通過前不發布。
