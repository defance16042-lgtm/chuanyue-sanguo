# 開發報告：v0.32.0

日期：2026-11-22　上一版：v0.31.0

## 這一版完成的項目（使用者本輪要求）
| 要求 | 結果 |
|---|---|
| 洞穴陶罐打破後要消失、不擋路 | 打破的陶罐不再繪製、不再阻擋 |
| 武器店／防具店／雜貨店分開，要有賣出 | 各城鎮分三種店；店內有買入、賣出（賣價為原價一半，價格 0 的裝備不能賣） |
| 角色資料用分頁 | 能力、計謀、裝備等共 5 頁；軍師會多一頁軍師計 |
| 陣形，最強八卦陣只有諸葛孔明 | 9 種一般陣形加八卦陣，選單「陣形」切換，存檔保留 |
| 計謀要更多、更有想法 | 新增 13 種計謀，並新增毒、持續回復、解除異狀、震暈、叫陣等機制 |

## 新計謀
毒煙計、蝕骨毒霧（持續扣兵力）、養息（持續回復）、清心訣、回春妙手（解除異狀並回復）、震懾、雷霆一喝（震暈，Boss 較難中）、叫陣（吸引敵人攻擊並提高防禦）、飲血刀（吸血）、斬將（對方兵力越少傷害越高）、狂怒（攻擊與速度提高）、水淹七軍（全體傷害加減速）、火燒連營（全體傷害加降防）。學習者：貓妖兩路線、劉備、關羽、張飛、曹操、盧植。

## 回歸中發現並修好的問題
店鋪分家時，長社「老學究書房」與宛城「工匠帳」被改成店，孫子兵法任務無法進行。已把防具店移到長社另一間屋、宛城武器店移到城外農舍，長社雜貨與宛城防具改為街上攤位。
