# 戰鬥敵將偵察資料規格

> 狀態：使用者已提出並確認需求方向；本文件是 UI／資料設計規格，尚未實作到遊戲。  
> 適用：戰鬥中點選敵方武將後，使用「偵察」查看完整敵將情報。

## 一、開啟方式與基本操作
- 戰鬥中選取敵方武將，點擊「偵察」開啟敵將情報視窗。
- 情報視窗採多分頁設計；每頁可獨立捲動，避免長資料被截斷。
- 頁籤可用滑鼠點選切換；保留上一頁／下一頁及頁碼提示，適合較窄的遊戲畫面。
- 關閉情報視窗回到原戰鬥畫面，不重置回合、不取消玩家目前選取。
- 若尚未完成偵察，未揭露的資料顯示「尚未取得情報」；偵察成功後才顯示已取得的完整資料。不要用猜測值填補空欄。
- 已偵察資料可在同一場戰鬥中再次查看；是否跨戰鬥永久保存，待資料與存檔系統確認後再決定。

## 二、分頁規劃

### 第 1 頁：人物情報
- 武將姓名、字／別名、陣營、官職、主將／副將身分。
- 等級、兵種、兵力、所屬部隊、所在位置。
- 生平與身勢描述：出身、經歷、性格、戰場習慣、擅長兵器、作戰風格。
- 外觀／身勢文字要具體，例如身高體格、姿態、盔甲、武器、氣勢與辨識特徵；只寫有資料支持的內容，不使用「身勢不明」以外的空泛句。
- 史實、演義與遊戲原創內容分別標記；演義角色設定不可冒充正史記載。

### 第 2 頁：能力值
完整列出敵將當前值、最大值及屬性來源：
- HP／最大 HP、MP／最大 MP。
- 武力、智力、統率、政治、速度／敏捷（依遊戲實際欄位）。
- 攻擊、防禦、命中、閃避、暴擊率、暴擊傷害、抗性。
- 士氣、狀態異常、增益／減益與剩餘回合。
- 兵力、兵種加成、陣形加成、裝備加成、計謀加成。
- 若某項數值由公式計算，顯示最終值及主要加成來源；不要重複計入裝備或陣形。

### 第 3 頁：裝備情報
依遊戲裝備槽逐項顯示：
- 武器、頭盔、盔甲、護腕、鞋、坐騎、飾品、特殊裝備（只列遊戲實際存在的槽位）。
- 裝備名稱、品質、等級／強化階級、稀有特性。
- 每件裝備的攻防與能力加成、特殊效果、套裝效果。
- 未裝備槽顯示「無」；未偵察到的裝備顯示「未知」，不得混用。
- 裝備加總頁列出對敵將最終能力值的增減。

### 第 4 頁：武技與特殊能力
- 普通攻擊、主動技能、被動技能、武將專屬技、特性。
- 技能名稱、等級、效果、傷害／倍率、範圍、目標類型。
- MP／士氣／其他消耗、冷卻時間、觸發條件、狀態效果及持續回合。
- 技能已使用、冷卻中或目前可用狀態。
- 重要技能說明其戰術用途與可應對方式。

### 第 5 頁：敵將計謀
逐條列出敵將本人可使用的計謀：
- 計謀名稱、分類、等級。
- 效果與作用目標（單體／全體／部隊／地形）。
- 消耗、成功率、範圍、冷卻／使用限制。
- 造成的傷害、控制、削弱、補給或特殊狀態。
- 施放條件、免疫／抵抗條件、玩家可用的破解方法。
- 戰鬥中已施放次數及目前是否可施放（若遊戲有追蹤）。

### 第 6 頁：軍師與軍師計謀
- 隨軍軍師姓名、等級、智力、軍師職責及目前狀態。
- 軍師計謀逐條列出名稱、效果、目標、消耗、成功率、範圍、冷卻與限制。
- 清楚區分「敵將本人計謀」與「軍師計謀」，不可混成同一清單。
- 若軍師不在場、被擊退、沉默或無法施計，顯示原因。
- 軍師計謀的抗衡方式、可打斷條件與優先威脅提示。

### 第 7 頁：兵種、部隊與陣形
- 兵種、兵力、部隊規模、統率／士氣。
- 目前陣形名稱、陣形效果、加成與弱點。
- 部隊移動、攻擊方式、射程、地形適性及特殊兵種能力。
- 主將／副將／軍師的配置與彼此加成（若實際系統有此配置）。

### 第 8 頁：戰場狀態與弱點
- 當前 HP／MP、兵力、士氣、狀態異常、增益／減益。
- 已揭露的弱點、抗性、免疫與特殊防護。
- 目前戰場位置、地形效果、與玩家部隊的距離／威脅範圍（依現有戰鬥系統）。
- 根據已取得資料提供簡短戰術建議：優先解除哪個狀態、先壓制軍師或先擊破主將等。
- 建議必須由資料規則產生或明確標示為策略提示，不要假裝是確定勝率。

### 第 9 頁：情報摘要／應對
- 威脅等級與主要危險來源。
- 最強技能、最危險計謀、軍師支援與裝備特效摘要。
- 已知弱點、推薦兵種／陣形／狀態應對。
- 偵察完成度與尚未揭露欄位。
- 摘要只重述前面已顯示的資料，不新增未經資料支持的數值。

## 三、資料與呈現規則
- 敵將資料應從遊戲現有角色、敵人、裝備、技能、計謀、軍師、兵種與陣形資料來源讀取；不要在 UI 另外複製一份容易過期的硬編碼資料。
- 需要補充的歷史人物身勢／生平文字，放在獨立敵將情報資料檔，標明史實／演義／遊戲原創來源類型。
- 所有數值使用遊戲內實際值；戰鬥中有臨時增減時，同時顯示基礎值與目前值。
- 長內容使用分頁＋頁內捲動；不能因資料多而把面板撐出畫面或裁切文字。
- 文字需繁體中文、清晰易讀；武將、裝備、計謀名稱保持資料一致。
- 情報視窗不得遮斷戰鬥流程；切頁、捲動、關閉都不應消耗回合。
- 對每名敵將建立完整資料時，先檢查既有資料欄位，缺少的內容列為待補，不得虛構歷史人物裝備或能力值。

## 四、驗收清單
- [ ] 戰鬥中可對敵方武將開啟偵察。
- [ ] 多分頁可切換，長頁可捲動，文字不被裁切。
- [ ] 人物身勢／背景描述清楚且標示史實、演義或原創。
- [ ] 能力值顯示基礎值、當前值及主要加成。
- [ ] 裝備各槽、裝備效果與加總正確。
- [ ] 敵將技能、敵將計謀與軍師計謀分開完整列出。
- [ ] 計謀顯示效果、目標、消耗、成功率／限制、破解方式（有資料時）。
- [ ] 情報視窗開關與分頁不消耗回合、不重置戰鬥。
- [ ] 無資料時明確顯示未知／未取得，不以空白或假數值替代。
- [ ] 新舊存檔相容；新增情報文字不破壞既有敵將資料。

## 五、開發狀態
目前為需求規格，尚未修改戰鬥 UI、敵將資料或遊戲程式。實作時先盤點現有敵將與計謀資料，再逐批補齊情報內容並測試。
