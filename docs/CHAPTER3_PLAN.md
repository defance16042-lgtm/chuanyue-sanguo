# 第三章企劃：兗州風雲（草案，v0.43.0 起實作）

接在第二章洛陽（曹操離隊、傳國玉璽線索）之後。基調：搞笑與嚴肅交替；貓妖越來越明白「歷史會被他改動」。

## 劇情（演義與正史混合）
1. 序：洛陽燒成焦土，劉備一行南下，回頭聽說曹操在陳留起兵、募兵練兵。貓妖察覺傳國玉璽被孫堅藏在井裡（正史線），決定追。
2. 徐州：陶謙讓徐州，曹操父親曹嵩遇害（演義為張闓所殺）。貓妖攔下護送隊，劇情分支只影響對話，不影響主線。
3. 兗州：曹操東征徐州時，呂布與陳宮襲取兗州。我方在濮陽被迫與呂布殘軍交手，火燒濮陽（典韋護主，典韋負傷但活下來）。
4. 小沛：劉備借居、呂布轅門射戟（搞笑關卡：用射箭小遊戲式戰前對話）。
5. 結尾Boss：下邳白門樓之前的前哨戰——高順的陷陣營（原創小隊戰）。章末貓妖得到一本新兵書線索，銜接第四章。

## 地圖
- 第三章獨立大地圖 'world3'（兗州、徐州、豫州東部），章間用渡口與關口（虎牢關東出口）銜接，並照第一章樣式用章節封鎖。
- 城：陳留、濮陽、小沛、下邳、徐州、東郡；村：3 座；洞穴：2 座（泰山寨、沂蒙山洞）；山口 1。
- 使用既有高清地形與 32px 人物，不新增圖塊種類。

## 人物與支線
