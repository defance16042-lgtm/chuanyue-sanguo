# 穿越三國 諸葛貓妖傳（戰鬥測試版 0.9）

步驟 3：加入戰鬥系統。地圖與對話仍是臨時測試用，沒有正式劇情。

## 怎麼玩
雙擊 `index.html`，用 Chrome 或 Edge 開啟即可，不需要安裝任何東西，也不需要網路。

| 操作 | 按鍵 |
| --- | --- |
| 移動 | 方向鍵 或 W A S D |
| 確認／對話／調查 | Z、Enter 或空白鍵 |
| 取消／開選單 | X、Esc 或 Backspace |

## 目前有的功能
- 標題畫面、開始新遊戲、讀取存檔
- 格子移動、碰撞（樹、水、牆、房屋、NPC）、NPC 面向
- 對話框（逐字顯示）與選項（選擇結果寫入劇情旗標）
- 門與換地圖（淡出淡入），兩張臨時地圖：涿縣、酒肆
- 角色資料畫面（唯讀）：字、稱號、職類、武器種類、特性、八項能力；裝備畫面（顯示能力差）；蘇雙的裝備店；敵人掉落；專屬武器
- 存檔：走到藍色水晶旁面向它按 Z，共 3 個欄位，存在瀏覽器裡；讀檔會檢查資料，壞檔不會當機
- 畫面 256×224 邏輯解析度，依視窗大小整數倍放大

## 0.2 新增（戰鬥）
- 回合制戰鬥：每回合先替每位隊員下指令（攻擊／計謀／道具／防禦／逃跑），再依速度出手
- 計謀耗戰術點（每回合自動回 1 點）。劉備：鼓舞、撫慰；關羽：青龍斬；張飛：怒喝
- 計謀可選「單體」（集中、威力大）或「全體」（分散、每人較輕、多耗 TP）：火計、亂世奇謀、撫慰；施放時有像素特效，智力越高火焰越旺
- 諸葛貓妖的技能看路線：武力路線＝猛擊、連斬(Lv3)、破陣(Lv5)；智力路線＝離間、火計(Lv3)、激勵(Lv5)。選了路線後不能更改
- 增益／減益／混亂狀態、逃跑（頭目戰不能逃）、道具（傷藥、提神茶、煙霧彈）
- 五項能力：武力、智力、速度、兵力、魅力（防禦由兵力換算）。魅力影響離間成功率、鼓舞／怒喝強度與逃跑成功率
- 升級：全員（含主角）依成長率自動隨機成長，沒有手動配點。能力：兵力、戰術點、武力、智力、速度、統率（全隊傷害）、運氣（暴擊／閃避）、守備（防禦）
- 地形：地圖有平地、森林、山、海（森林／山／海都可以走過去）。角色與敵人各有四種地形的適性（S＋12%／A＋6%／B／C－10%，影響攻擊與防禦），戰鬥背景依踩著的地形變化
- 偵察：戰鬥指令「偵察」可看敵人資料（不耗回合）
- 第一章 中原篇（一）：潁川道 → 長社 → 皇甫嵩的火攻計 → 波才（Boss 戰第 2、4 回合結束敵全體受火燒）；曹操助戰入隊
- 第一章 中原篇（二）：汝南（彭脫，森林系 Boss）→ 宛城（趙弘 → 韓忠＋孫夏；朱儁、孫堅登場）。卜巳、冀州三張之後製作
- 第一章 中原篇（三）：東郡倉亭（卜巳，Boss 戰）；打完後曹操離隊。下一批：冀州篇（張梁、張寶、張角、三張合體）
- 第一章 冀州篇（上）：冀州路 → 廣宗（盧植助戰、Boss 張梁、左豐索賄、盧植被徵召）。下一批：張寶、張角、三張合體
- 第一章 冀州篇（下）：下曲陽（張寶）→ 廣宗城內（張角 → 三張合體）。第一章完結，劉備授安喜縣尉；第二章製作中
- 捲土重來：打倒過的頭目，之後野外遇敵有 5% 機率換成同名頭目（能力與原本頭目完全相同，可能掉裝備）
- 計謀隨等級進化：各角色有自己的計謀路線（例：劉備 Lv8 大撫慰、Lv16 仁者無敵；諸葛貓妖智謀路線 Lv10 烈火計、Lv18 業火計），學會後取代低階計謀，升級時會顯示
- 助戰：別陣營的角色（鄒靖）暫時入隊，故事結束就離隊
- 戰鬥畫面仿紅白機排列，左我方右敵方；全體攻擊指令；人物不分地圖或戰鬥都是 16×16，四位主角各有武器與揮砍／施法動作
- 金錢、旅館住宿（30 金）、商人買道具、野外隨機遇敵、頭目戰、戰敗後回涿縣（損失一半金錢）
- 存檔包含金錢與道具；舊存檔仍可讀取

### 測試地圖上的東西
- 涿縣：劉備(14,8)、關羽、張飛可招募；村民＝路線選擇；商人＝買道具；酒肆老闆＝住宿；南邊出口通往野外
- 野外：隨機遇敵；最南端是頭目程遠志

## 還沒有的功能

## 資料夾
```
index.html            雙擊開啟
src/                  程式（engine 引擎、game 進度、scenes 場景、save 存檔、battle_logic 戰鬥規則、battle_scene 戰鬥畫面、main 進入點）
data/                 資料（characters 角色、maps 地圖、dialogue 對話、battle 敵人／技能／道具／經驗表）
assets/               圖片（tiles 圖塊、sprites 地圖人物（含村民、程遠志）、objects 水晶、battle_party16／battle_enemy16 戰鬥小人、portraits 大頭像）
tools/build_assets.py            地圖圖塊與所有地圖人物（16×16）
tools/build_battle16.py          戰鬥小人（身體 16×16，與地圖 NPC 同大小，含武器動作）
tools/build_from_sheet.py        從 tools/source/character_sheet.png 裁出四位主角的大頭像
tools/sim_battle.js   戰鬥平衡模擬：node tools/sim_battle.js force 5（路線、野外戰鬥場數）
tests/                用無頭瀏覽器按鍵測試（需要 Node 與 Playwright）
```

## 想自己改
- 換圖：把 `assets` 裡的 PNG 換成你自己的圖，尺寸與排列相同，同名放回去即可。
  `tiles.png` 是 9 個 16×16 圖塊排成一列；`sprites.png` 每列一個角色，每列 8 格，順序為
  下×2、上×2、左×2、右×2。
- 改地圖與對話：直接編輯 `data/maps.js`、`data/dialogue.js`；調數值改 `data/battle.js`、`data/characters.js`。
- 重新生成圖片：`python3 tools/build_assets.py`（需要 Pillow）。

## 備註
- 存檔存在瀏覽器的 localStorage，換瀏覽器或清除網站資料就會消失。
- 這版是用無頭瀏覽器模擬按鍵測試過，操作手感和畫面是否順眼仍需實際遊玩確認。
