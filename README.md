# 穿越三國・諸葛貓妖傳

一款以三國時代為舞台、融合像素風探索與回合制策略戰鬥的原創 RPG。玩家將跟隨諸葛貓妖與劉備、關羽、張飛等角色踏上旅程，穿越中原各地、探索城鎮與洞穴，迎戰黃巾軍及各路群雄。

> **目前開發版本：v0.26.1**  
> **最新已發布 Release：v0.26.0**  
> v0.26.1 已更新於 `main` 分支；正式 Windows 安裝包請以 Releases 頁面為準。

## 目前遊戲內容

### 大地圖與探索
- 中原大地圖，可在城鎮與區域之間自由旅行。
- 多座城鎮分布於大地圖，各地具有不同地形與區域等級。
- 城鎮建築可進入探索，並可與 NPC 對話、觸發事件。
- 野外依區域設定遭遇敵人，探索時可能觸發戰鬥。
- 地圖包含森林、山地、平原、水域等地形；地形會影響角色與敵人的戰鬥適性。
- 大地圖城鎮具有旗幟與攻陷狀態等資料。

### 城鎮、洞穴與事件
- 城鎮內可探索建築、與 NPC 互動，並取得劇情線索。
- 洞穴採多層結構，包含樓梯、守路頭目、特殊 NPC 與存檔水晶。
- 洞穴中配置火把、骨堆、雕像、石碑、陶罐、靈泉、拉桿及石門密室等環境物件。
- 部分洞穴頭目與寶箱屬於可選擇探索內容。

### 回合制戰鬥
- 戰鬥採回合制指令系統，依角色速度決定出手順序。
- 可使用攻擊、計謀、道具、防禦、偵察及逃跑等指令；部分頭目戰限制逃跑。
- 計謀消耗戰術點，戰術點會依回合規則恢復。
- 角色擁有不同計謀路線與技能，部分技能會隨等級進化。
- 支援單體與全體攻擊、增益／減益、混亂等狀態效果。
- 武器種類具有不同攻擊特效。
- 戰鬥中可查看敵人資料，並依地形適性影響攻防表現。
- 曾擊敗的頭目可能在後續野外遭遇中再次出現。

### 角色、隊伍與成長
- 可查看角色能力、稱號、職類、武器種類、特性與裝備能力差異。
- 角色升級時依成長率提升能力，無需手動分配點數。
- 隊伍編成可調整出戰順序及軍師；軍師可提供隊伍戰術點加成。
- 劇情助戰角色會依故事進度暫時加入或離隊。
- 角色能力包含兵力、戰術點、武力、智力、速度、統率、運氣及守備等項目。

### 商店、道具與存檔
- 可向商人購買道具，並使用旅館恢復隊伍狀態。
- 戰鬥可取得金錢、經驗與掉落道具。
- 支援多個存檔欄位，存檔資料保存在目前瀏覽器的本機儲存空間。
- 讀取存檔時會檢查資料，避免損壞資料直接造成遊戲當機。
- 存檔會保留金錢與道具；舊版存檔是否相容仍以實際版本測試為準。

## 劇情進度

目前已製作的章節與事件包含：
- **第一章・中原篇：** 潁川道、長社、汝南、宛城、東郡倉亭等事件。
- **第一章・冀州篇：** 冀州路、廣宗、下曲陽，以及黃巾軍三兄弟相關戰役。
- **第二章・群雄逐鹿：** 安喜縣、太行山道、幽州北境、平原、酸棗與汜水關等事件。

劇情與地圖仍持續開發中，部分事件、場景及後續章節尚未完成；實際遊戲內容以目前程式版本為準。

## 專案結構

```
index.html             遊戲入口
src/                   遊戲引擎、場景、存檔、戰鬥邏輯與戰鬥畫面
data/                  角色、地圖、對話、敵人、技能、道具等遊戲資料
assets/                地圖圖塊、角色、物件、戰鬥人物與頭像素材
desktop/               Electron 桌面版主程序、預載入與更新介面
tools/                 地圖／素材產生及戰鬥模擬工具
tests/                 自動化測試
.github/workflows/     GitHub Actions 建置與發布流程
```

## 開發與建置

需要 Node.js（建議使用專案工作流程所設定的 Node.js 22）及 npm。

```bash
npm ci
npm start
```

建置 Windows 安裝包：

```bash
npm run dist:win
```

建置產物輸出至 `dist/win`。GitHub Actions 會依專案工作流程建置 Windows 安裝包；發布流程與版本 Tag 必須符合工作流程設定。

## 自動更新

- Windows 桌面版使用 Electron 與 electron-updater 檢查更新；下載完成後可在遊戲內重新啟動並安裝。
- 瀏覽器版會讀取專案的 `update.json` 比對版本；若有新版，會提供前往下載的位置。
- 瀏覽器版的存檔保存在該瀏覽器的本機儲存空間；更換瀏覽器或清除網站資料可能導致存檔無法保留。

## 素材與資料修改

- 地圖、對話與角色／戰鬥資料位於 `data/`。
- 圖片素材位於 `assets/`。
- 部分地圖與素材由 `tools/` 中的產生程式建立；若要修改產生結果，請先修改對應工具，再重新產生資料。
- 修改前建議先備份存檔與原始素材。
