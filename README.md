# 穿越三國・諸葛貓妖傳

以三國時代為舞台的原創 PC RPG，融合像素風大地圖探索、城鎮／洞穴事件與回合制策略戰鬥。玩家將跟隨男性主角諸葛貓妖，與劉備、關羽、張飛及各路武將踏上旅程。

> **目前開發版本：v0.53.0**  
> **最新已發布 Release：v0.53.0**  
> 版本資訊以 `package.json`、`package-lock.json`、`src/version.js`、`update.json` 為準；Windows 安裝包請以 [Releases](https://github.com/defance16042-lgtm/chuanyue-sanguo/releases) 頁面為準。

## 目前遊戲內容

### 大地圖與探索
- 多章節獨立大地圖，可在城鎮、村落與野外區域旅行。
- 森林、山地、平原、水域、沙漠等地形與區域等級。
- 城鎮可進入房屋、商店、客棧，與 NPC 對話並觸發劇情。
- 洞穴多層探索，包含樓梯、守路頭目、寶箱、機關、密室與存檔水晶。
- 關口、山口、渡口及章節封鎖依劇情旗標開放。

### 回合制戰鬥
- 依速度安排回合順序，可使用攻擊、計謀、道具、防禦、偵察、陣形與逃跑等指令。
- 計謀消耗戰術點，包含傷害、治療、增益、減益、持續效果、復活及軍師專屬計謀。
- 支援單體／全體攻擊、狀態效果、地形適性、戰鬥特效與音效。
- 可在野外遭遇主線頭目殘部，進行再次戰鬥及招收武將。

### 角色、隊伍與成長
- 角色能力、稱號、職類、武器種類、特性與裝備能力。
- 自動成長與經驗升級；可調整隊伍、軍師、陣形及裝備。
- 最多 8 名隊伍成員，戰鬥最多 5 人出戰，其餘為後備。
- 劇情助戰角色依故事加入與離隊；招收武將可在招收館管理。

### 道具、商店與存檔
- 武器、防具、道具、兵書、商店買賣、旅館恢復與寶箱獎勵。
- 背包分為道具、裝備與兵書；兵書裝備後可提供相應計謀。
- 多個存檔欄位，瀏覽器版存於本機瀏覽器儲存空間。
- Windows 桌面版使用 Electron 與 electron-updater 更新。

## 劇情進度

- **第一章・黃巾之亂：** 涿縣、廣陽、潁川、長社、汝南、宛城、東郡倉亭、冀州廣宗、下曲陽、鉅鹿等主線與戰役。
- **第二章・群雄逐鹿：** 安喜、太行山道、幽州北境、平原、酸棗會盟、汜水關、虎牢關與洛陽徐榮。
- **第三章・兗州風雲：** 陳留、東阿、濮陽、小沛、徐州、下邳等地；主線、村莊、泰山寨、沂蒙山洞、鉅野山口與支線《三略》。
- **第四章・許都風雲（批次 1）：** world4 與許都、汝南、官渡、延津、白馬、鄴城六城；主線進度包含煮酒論英雄、衣帶詔、車冑、曹操／袁紹陣營事件，至顏良、文丑與官渡前半段。

**第四章尚未完成：** 關羽辭曹、千里走單騎／過五關、後續關口與支線、烏巢及官渡之戰等內容，將在後續版本接續製作。實際可遊玩內容以目前版本程式為準。

## 專案結構

```
index.html             遊戲入口與載入順序
src/                   引擎、場景、存檔、戰鬥邏輯與畫面
data/                  角色、地圖、對話、敵人、技能、道具與章節資料
assets/                原創地圖、角色、戰鬥人物、頭像與特效素材
desktop/                Electron 桌面版主程序、預載入與更新介面
tools/                 地圖、角色、素材產生及戰鬥模擬工具
tests/                 自動化回歸測試
docs/                  章節企劃、交接與開發紀錄
.github/workflows/      GitHub Actions 測試、建置與發布流程
```

## 開發、測試與建置

需要 Node.js 22 及 npm。

```bash
npm ci
npm start
```

Windows 安裝包建置：

```bash
npm run dist:win
```

GitHub Actions 會安裝 Playwright／Chromium，依序執行 `tests/*_test.js` 回歸測試，再建置 Windows 安裝包。若測試或建置失敗，該工作流程會停止，不會繼續發布。

## 自動更新與存檔提醒

- Windows 桌面版啟動時檢查更新；下載完成後可重新啟動安裝。
- 瀏覽器版會讀取 `update.json` 比對版本並提供下載位置。
- 瀏覽器存檔保存在該瀏覽器本機；更換瀏覽器或清除網站資料可能造成存檔遺失。
- 舊版本存檔相容性以各版本實際測試結果為準。

## 素材與資料修改

- 地圖、對話、角色與戰鬥資料位於 `data/`。
- 圖片素材位於 `assets/`；部分素材由 `tools/` 產生。
- 修改產生器管理的素材時，請先修改對應工具再重新產生，避免只改輸出檔而下次生成被覆蓋。
- 開發前建議備份存檔與原始素材。
